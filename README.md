## 📱 平台适配说明

本语言包均为 **测试版本 (Beta)**，目前各平台的适配情况如下：

### 🇨🇳 简体中文包
* **全平台最佳支持**：Android、iOS、macOS、Desktop (桌面端) 均已正常适配！

### 🇨🇳 繁体中文包
* **完美支持**：Android、iOS、macOS (MAC)
* **⚠️ 桌面端 (Desktop) 说明**：由于 Telegram 官方系统的已知 Key 错误问题，更换多个语言包文件后依然存在报错，目前**桌面端暂无法正常适配繁体中文**。建议桌面端用户优先使用简体中文包。
